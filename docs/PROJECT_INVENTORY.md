- Founder is the user's supplied self-description. No company incorporation, funding, award, affiliation or credential is implied.
- Keep the requested six as the main body. Do not dilute the page with unrelated repositories.
- Public featured copy uses a one-line purpose, two or three capabilities, one source-backed implementation distinction and an explicit access/status note.
- Keep the public SatQuery and GhostTrace specimens. Use the user's selected complete Warscythe, REFLEX and Flood Lab captures, plus the explicitly authorized REGULENS dashboard. Screen values are not accuracy decorations.
- Only the authorized synthetic-demo REGULENS screenshot enters the profile package. Its private documents, datasets, benchmark values and submission files stay excluded. The private repository is never linked as publicly accessible.

- Do not repeat the Warscythe README's zero-latency, absolute-integrity, projected-user or health-effect wording.
- The special profile repository returned 404 through the connected account. Recheck immediately before creating it. Nothing has been created remotely.
